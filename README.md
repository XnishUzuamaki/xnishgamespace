# LowGX
Graphics optimizer (ANGLE + render scale) using Shizuku. Liquid glass purple UI.

## Build
Push ke GitHub -> tab **Actions** -> **Build APK** -> muat turun artifact `LowGX-debug`.

## Guna
1. Pasang & mulakan Shizuku.
2. Buka LowGX, ketik kad Shizuku untuk beri kebenaran.
3. Pilih game, pilih Blur/Pixel + level, tekan Save changes.
